# Tic-Tac-Toe React App 

# Getting Started

## GitHub

To get started you need to clone the repository in GitHub. 

1. Select the drop down on the green '<> Code' button.
2. In the 'Local' tab, enure HTTPS is selected.
3. Copy the link (it will start with https://github....)
4. Open Visual Studio Code
5. On the top left hand menu select 'Terminal' --> 'New Terminal'
6. Paste the link in the terminal
7. Select a place in your file explorer to store it
8. Youre In !

## Running The Project

1. Install Node.js
2. Run `npm install` in the terminal  (not including the back ticks)
3. Run `npm start` in the terminal

The app should open at `https://localhost:3000`

## Notes

- You should only need to run `npm install` once at the start. 
- If the app does not start after `npm start` try running it `npm install` again.
- Save your files to see your changes in the browser.
